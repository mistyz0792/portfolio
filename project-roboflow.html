TEACH ITTO SEE

Shoot the frames, draw the boxes, train the model — until it draws the boxes itself.

scroll through the dataset

01

It starts with
photographs you took.

There was no dataset to download. The objects were arranged and shot in place — one camera, one angle, one light — and that choice is what caps how good the model can ever get.

02

Every box gets drawn
by hand first.

Each object gets a bounding box and a class, red against yellow, one at a time. It is dull work, and it is the entire model — label it wrong and it learns exactly that.

03

Version it,
then train.

Roboflow keeps the dataset as versions, so a round of relabelling and retraining can be compared against the last one. The mAP curve is how you know whether the fix actually helped.

04

After that,
the boxes appear on their own.

The trained model puts every box up in one frame, with a class and a confidence beside each one — the same work that was done by hand a moment earlier.
